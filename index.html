Your password is never stored in plain text — only a one-way cryptographic hash is saved.

Security Note

This offline version stores data locally in the browser (IndexedDB). Login uses a hashed password, but this remains a client-side app — anyone with access to this device's browser storage or developer tools could potentially bypass it. Use Backup & Restore regularly, and keep the exported JSON file somewhere safe. For multi-computer production use, a secure server/database with roles, audit logs and encrypted backups is recommended.
